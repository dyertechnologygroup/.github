## What we do

We set up, secure, and look after the technology people rely on every day, either on-site or remotely.

| | |
|---|---|
| 📶 **Wi-Fi & networking** | Mesh systems, router hardening, dead-zone fixes, printers that connect |
| 💻 **Device setup** | Phones, laptops, tablets and TVs configured, with data migrated safely |
| 🏠 **Smart home** | Cameras, doorbells, thermostats, lighting and speakers working together |
| 🔒 **Security & privacy** | Password managers, two-factor login, scam protection, account clean-ups |
| ☁️ **Backups & photos** | Automatic backups and organized photo libraries |
| 🏢 **Small office IT** | Onboarding and offboarding, network and device management, vendor coordination for teams of 2 to 25 |

## What lives here

This organization holds the code and configuration behind our own operations: infrastructure, automation, and internal tooling. Most repositories are private because they describe client environments.

When we build something that might help others, such as scripts, templates, or home-network guides, we publish it here as a public repository.

## Working with us

- **Clients:** book through [dyertechnologygroup.com](https://dyertechnologygroup.com). Please don't open GitHub issues for support requests.
- **Security reports:** if you find a vulnerability in anything we publish, contact us privately through [our contact page](https://dyertechnologygroup.com/contact.html) rather than filing a public issue.
